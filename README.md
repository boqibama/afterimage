# AFTERIMAGE 👁️

**Don't blink or you'll miss it.**

▶️ **[Play it here](https://boqibama.github.io/afterimage/)**

Afterimage is a daily drawing memory game set up like an eye exam. You get 10 seconds to study a drawing. Then the eye blinks shut and you have 1 minute to redraw it from memory. Your score comes back as a vision rating on an eye chart, and 20/20 is the goal.

## How to play
1. **Look:** 10 seconds, eyes wide open.
2. **Draw:** 1 minute to redraw it from memory with the pen, eraser, undo/redo, and clear tools.
3. **Score:** get your % match and a vision rating, from *Time for Glasses* up to *20/20 Recall*. Compare your drawing with the original as an overlay or side by side.

## Game modes
- **Daily:** one chart a day, and everyone gets the same drawing. Build a streak.
- **Endless:** chart after chart. See how long your eyes hold out.
- **Party:** 2–4 players pass the mouse and draw the same picture. Whoever scores highest wins the lineup.

## Features
- **Scoring:** both drawings are rasterized and compared with a tolerance, so close lines still count. The score balances how much of the original you captured against how much of your drawing was actually on it.
- **Animated eye mascot:** it blinks, follows your cursor, and reacts to your score.
- **Stats:** days played, average, best, current and longest streak, plus a chart of your last 7 dailies, all saved in your browser.
- **Share card:** copy your result to send to friends.
- **Settings:** sound, reduced motion, and timer reminders.

## Built with
React 18, HTML Canvas, and the Web Audio API, packed into one self-contained HTML file (`index.html`), with no server or install. It's hosted on GitHub Pages.

## Run it locally
Download `index.html` and open it in a browser.
